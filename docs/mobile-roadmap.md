# Mobile App Roadmap

This roadmap starts the project from the mobile app side first and lays out a 3-week delivery sequence with deadlines.

## Week 1: Mobile foundation

| Issue | Scope | Duration | Start Date | Deadline |
| --- | --- | --- | --- | --- |
| 1. Define mobile app scope and screens | Confirm app roles, core screens, and navigation flow for donor and hospital users | 1 day | Aug 3, 2026 | Aug 3, 2026 |

| 3. Build UI theme and reusable components | Define colors, typography, buttons, inputs, cards, and layout patterns | 1 day | Aug 6, 2026 | Aug 6, 2026 |
